# Playhouse CAD Model

A custom two-story playhouse design for Smiski. Designed using Onshape, this model has living spaces including a kitchenette, seating area, ladder access, and a loft space.

## Features & Layout

### Ground Floor
* **Lounge & Seating Area:** Includes two high sofa chairs and a central table.
* **Kitchenette & Storage:** Refrigerator unit, base cabinets, counter space, and wall-mounted storage grid/shelving.
* **Arched Windows:** Decorative gothic-style arched window for natural light.

### Upper Loft & Access
* **Access Ladder:** Features multi-tone rungs for vertical travel.
* **Loft Space:** Features low-profile stool seating/table setup, bed setup, and an extended side balcony guardrail.
